## 🧮 Core Mathematical Formulas

### 1. Reverse Invoice Formula (PayPal & Stripe)
To ensure you receive exactly your target net payout after transaction deductions:

$$\text{Gross Charge} = \frac{\text{Target Net} + \text{Fixed Fee}}{1 - \text{Percentage Rate}}$$

### 2. TikTok Shop Net Profit Per Unit
$$\text{Net Profit} = \text{Customer Price} - \text{COGS} - \text{Shipping} - \text{Referral Fee} - \text{Creator Commission} - \text{Estimated Return Loss}$$
